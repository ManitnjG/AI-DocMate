# AI DocMate

Native Android AI document assistant for PDF/image analysis, summaries, document Q&A, extraction, translation and comparison.

## MVP
- Import PDF/image documents
- Local document history
- Summary and Ask Document UI
- Tamil / English ready
- AI calls are designed for a backend proxy; never embed provider keys in the APK

## Build
Open with Android Studio or run `./gradlew assembleDebug` when using a generated Gradle wrapper.
